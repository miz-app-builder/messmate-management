# MessMate Management

MessMate is a mess meal and accounts management system.

## Core modules

- Mess creation and join by code/QR
- Manager approval and active membership
- Member permissions and Bazar Manager role
- Daily breakfast/lunch/dinner meal tracking
- Meal off and configurable cut-off times
- Automatic next-meal generation and unconfirmed-meal default
- Bazar entry and approval workflow
- Member deposits, expenses, ledger and balances
- Meal-rate calculation
- Monthly settlement and reports

## Backend

Supabase PostgreSQL, Auth, Row Level Security and Storage.
